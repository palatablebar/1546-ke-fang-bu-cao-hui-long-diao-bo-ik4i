# 客房布草回笼调拨数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `checked_out` | 当班退房 | 间 | 8–180 |
| `on_hand` | 可发净布草 | 件 | 0–480 |
| `truck_eta` | 送洗回车预计 | min | 15–240 |
| `towel_issue` | 毛巾追加领用 | 件 | 0–155 |
| `wash_reject` | 待洗件剔除 | % | 0–23 |
| `concert_rooms` | 团体锁定房 | 间 | 0–110 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。实绩单位为件。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`；此时 `outcome` 是洗房抢先补货后已核实的缺口下界，而不是完整实绩。

下界单与完整实绩单使用同一套截止时间规则：到站、结果/下界核实时间必须落在对应窗口半开区间内，晚到单据不进入该窗。下界可以进入拟合，但其损失只在估计低于下界时为正；校准区间和回放误差只使用 `observed=true` 的完整实绩。回放临界判断把“下界已到复核线且估计未到线”计入 `漏查`，把“下界未到线”计入 `留待核实`/`待核实`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 退房交接 | `checked_rooms` | 退房交房间 | 1 | 0 |
| 退房交接 | `available_pieces` | 净件可领取数 | 1 | 0 |
| 净成品入笼 | `truck_arrival_sec` | 车辆回场倒计时秒 | 60 | 0 |
| 净成品入笼 | `reserved_towels` | 预领巾类件数 | 1 | 0 |
| 洗涤派车 | `reject_basis_points` | 待洗剔除万分数 | 100 | 0 |
| 洗涤派车 | `blocked_group_rooms` | 团队锁定房间 | 1 | 0 |

示例见 `sample_data/linen_cages_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[2,40)`、校准 `[43,62)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `service_pressure` | 补发差额 | `checked_out*2+towel_issue-on_hand` |
| `eta_risk` | 回车有效迟滞 | `truck_eta/60*(1+wash_reject/15)` |
| `block_ratio` | 团体比重 | `concert_rooms/(checked_out+10)` |
| `usable_linen` | 可用成品 | `on_hand*(1-wash_reject/100)` |
| `resupply_density` | 增领密度 | `towel_issue/(checked_out+1)` |

### 局部加权缺口分位

以标准化距离和同店偏好选取邻居。在反距离权重下取第 72 百分位，针对缺货成本保留较高缺口估计。

本工作台的独立样本校准方式为库存短缺不对称区间。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较分区累积分布差。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 安排同城调拨

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `CLEAN_STOCKOUT` | `on_hand < 35 and checked_out > 112` | 净布草库存不足 |
| 2 | `WASH_TRUCK` | `truck_eta >= 170 and wash_reject >= 12` | 送洗回车迟到 |
| 3 | `GROUP_ARRIVAL` | `concert_rooms >= 64 and on_hand < 120` | 锁房团到店，预留调拨 |

第一条为暂停规则。其余命中与模型阈值 `95` 共同决定是否列入候选。单据所需工位数按 `1 + int(checked_out >= 65) + int(concert_rooms >= 60)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 整笼调拨单

净布草扣除当班换洗、团体锁房和门店安全量后可外拨。每笼 12 件，发出门店与接收门店必须不同。未补齐的需求进入等待洗房回告清册。 在派发环节展开现场安排，或从关联单据回查实际读数。
